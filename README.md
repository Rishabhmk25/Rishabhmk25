### 🔬 [Physics-Informed Neural Networks for Rotor Condition Monitoring](https://github.com/Rishabhmk25/Physics-Informed-Neural-Networks-for-Rotor-Condition-Monitoring)

**Physics-informed deep learning | PyTorch • Autograd • LBFGS • Scientific ML**

Replication and improvement of a PINN-based rotor condition-monitoring method for solving an inverse dynamics problem.

* Infers five physical health parameters from rotor displacement signals.
* Neural network predicts system trajectories while satisfying the governing equations of motion.
* Three-stage optimization pipeline: data fitting → linear least squares parameter identification → joint PINN fine-tuning.
* Fourier-aware inputs `[t, cos(Ωt), sin(Ωt)]` improve convergence and derivative quality.
* Evaluated across clean and noisy operating scenarios.

**What it demonstrates:** scientific ML + optimization + numerical reasoning + research replication.
